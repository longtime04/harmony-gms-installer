# 谷歌服务安装助手（HarmonyOS GMS Installer）

给华为鸿蒙手机装谷歌服务框架 + Play 商店的**向导式安装器**：打开 App，照着 9 步卡片一步步点，检测自动打勾，做完一步解锁下一步。

已在鸿蒙 4.2 真机完整实测：Play 商店可登录、可正常下载应用。

| HarmonyOS 4.2 及更早（2.0 / 3.0 / 4.0 / 4.2） | ✅ |
| HarmonyOS 4.3 | ⚠️ 未验证（助手激活环节可能失败） |

判断只看系统版本号（设置 → 关于手机），与型号无关；老机型升级到 5.0 后同样不支持。

## 9 步流程

1. 关闭自动日期，日期改到 2018 年
2. 给华为「备份」App 开全部权限
3. 写入备份数据 → 在备份 App 里「从内部存储恢复」（密码自动复制到剪贴板）
4. 打开谷歌服务助手，激活设备管理器并允许权限
5. 日期改回自动
6. 安装 Play 框架（GSF Proxy）
7. 安装 Play 服务（microG 华为版）
8. 给 microG 开全部权限 + 电池不受限制
9. 安装 Play 商店，连外网打开登录

说明：安卓系统不允许普通 App 静默安装，每个安装包仍需用户本人在系统弹窗里点一次「安装」，这是系统硬限制，任何安装器都绕不过。

## 构建

本仓库只包含安装器源码。构建前需自备 4 个第三方 payload 文件（清单、包名、版本、sha256 见 [PAYLOAD.md](PAYLOAD.md)），放入 `assets/payload/`，并准备自己的签名 keystore，然后：

```bash
./build.sh
```

构建走手动流水线（aapt2 → javac → d8 → zipalign → apksigner），需要 JDK 21 与 Android SDK build-tools 34。

## 已知限制

- microG 方案不是原生谷歌框架：依赖 Play Integrity 强校验的应用（部分银行 App、个别游戏）可能不可用；Google Pay 不可用。
- 包内 Play 商店为安卓 12 底子版本；安卓 10 底子的老机型（鸿蒙 2.0）需另换低版本商店包。
